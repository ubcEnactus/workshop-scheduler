# Admin quick-start guide

Use this order for everyday setup and scheduling:

**School → teacher/class → availability → workshop → date → PAs → publish**

All dates and times in the app use Vancouver time.

## 1. Add a school

1. Open **Schools & teachers** from the menu, then select **Schools**.
2. Under **Add school**, enter the school name.
3. Select **Add school**.

Add the school before adding any of its teachers.

## 2. Add a teacher and their class

1. Return to **Schools & teachers**.
2. Under **Add teacher**, enter the teacher's name and email, then select their school.
3. Select **Add teacher**.

Each teacher represents one class, so there is no separate class form. To add another class, add its teacher.

## 3. Record when the class is available

1. Open the teacher and choose **Availability**.
2. Under **Weekly availability**, select **Add weekly time**.
3. Choose the weekday(s), start and end time, and the date the schedule begins. Add an end date only if needed.
4. Select **Save weekly time**.

For a one-off change, select the date on the calendar. Use **Add a time** for extra availability, or remove that date's usual time if the class is unavailable. Availability creates possible choices; it does not book a session.

## 4. Create and schedule a workshop

1. Open **Workshops** and select **Create a workshop**.
2. Enter the workshop title, session length, minimum and maximum number of PAs, and the shared delivery start and end dates.
3. Select **Create a workshop**, then **Add teachers** and choose the classes taking part.
4. In **1. Plan**, choose one date and time for each teacher you are ready to schedule.
5. Select **Save dates & continue**. The sessions are saved privately; nothing is visible to teachers or PAs yet.
6. In **2. Staff**, select the sessions and use **Auto-fill missing PAs**, or assign PAs yourself. Review any availability or workload warnings.
7. In **3. Publish**, check the dates and PA teams, select the ready sessions, and choose **Publish**.

Publishing makes the sessions visible in the app, but it does **not** send an email or message. Contact the school and PAs separately.

## Helpful reminders

- If a teacher has already confirmed an exact date, use **Schedule a confirmed teacher session** from the admin overview or calendar, then staff and publish it as usual.
- A teacher receives one active session per workshop. For another visit, create another workshop.
- Use one representative teacher and an internal note when two classes attend together.
- **Auto-fill missing PAs** never changes dates or replaces PAs already assigned.
- Draft sessions stay private until an admin publishes them.
